# Mochi MD

一个轻量、私人的 Markdown 阅读与编辑器原型。

## 运行

无需安装依赖，直接用浏览器打开 `index.html` 即可。为了获得完整的本地文件能力，推荐在此目录执行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已实现

- Markdown 编辑、即时预览、分屏模式
- 新建文档、本地持久化、自动保存提示
- 打开本地 Markdown、导出 Markdown
- 收藏、最近文档、专注模式
- 字数、行数、光标位置、阅读时间
- 巧克力、草莓、像素、淡紫莓果、极简 Ins、程序员六套主题
- 桌面端与移动端适配

当前版本是零依赖交互原型，可作为后续 Tauri 桌面版本的 UI 与功能基础。
