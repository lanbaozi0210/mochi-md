# Mochi MD 0.4.0

## 使用方式

1. 解压 `Mochi MD-macOS.zip`。
2. 将 `Mochi MD.app` 拖入“应用程序”文件夹，或直接双击运行。
3. 点击左侧“打开本地文件”读取 `.md`、`.markdown` 或 `.txt` 文档。
4. 编辑后点击右上角“保存”或按 `⌘S` 写入文件；已保存到磁盘的文件会直接覆盖原文件。
5. 有未保存修改时，切换文档或关闭窗口会询问“保存 / 不保存 / 取消”。
6. 点击左上角头像，可以选择任意图片；应用会自动居中裁切为方形并记住设置。
7. 点击右上角“导出”，可以按当前预览样式导出 PDF，或另存为新的 Markdown 文件。

## 已包含

- 原生 macOS 窗口与文件选择、保存面板
- 编辑、预览、分屏和专注模式
- 手动保存、修改状态提示与关闭确认
- `⌘Z` 撤销、`⇧⌘Z` 重做
- 顶部“导出”按钮与 PDF、Markdown 导出
- 巧克力、草莓、像素、淡紫莓果、极简 Ins、程序员主题
- 收藏、字数、行数、阅读时间与快捷键

这是 Apple Silicon 版本，适用于 M 系列芯片 Mac。
